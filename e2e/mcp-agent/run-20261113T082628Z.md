## Friction (owner -> suggested fix)

See `private/STATE.md` "## mcp-agent e2e" for the full list. The top items:
1. **apps/mcp bug**: the resolution-window floor is counted from market expiration, but Court counts from `observation.at`. With the guide's own defaults (5x3m, window 20) and expiration before observation, the link is permanently rejected. Compute the floor at `/plan` time as `obs + attempts*every + 5m - (now + duration)`, with a margin.
2. **apps/mcp bug**: `market_create_link` re-renders the rules without the simulated sha, so the registered spec_hash differs from the one `rules_render` showed, and the registered rules say "Simulated ... unknown: no".
3. **apps/mcp**: a fixed `duration_minutes` lets a late signer create a market that expires after observation. Clip or refuse at `/plan`.
4. **apps/mcp**: receipts have no tx hashes or OutLayer request id, no link-rejection reason in market_status, `verdict_get` errors before a verdict exists, and no server time.
5. **apps/mcp**: tools have no MCP annotations, so Codex `exec` blocks every call until the client sets `default_tools_approval_mode = "approve"`.
